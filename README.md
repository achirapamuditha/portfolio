## ⚡ Quick Start
Follow these steps to run the portfolio locally.

### Prerequisites
A code editor such as VS Code. No Node.js or npm is needed.

### Setup Instructions
1. **Clone the repository:**
   ```bash
   git clone https://github.com/achirapamuditha/portfolio.git
   cd portfolio
   ```
2. **Open the folder in VS Code** and start it with the **Live Server** extension (right-click `index.html`, then **Open with Live Server**). You can also open `index.html` directly in a browser.
3. **Edit your content** in the `EDIT YOUR CONTENT HERE` block of the script (name, roles, projects, skills, certificates).
4. **Contact settings** are constants near the Contact code: `EMAIL`, `PHONE`, `PLACE`, `MAP_QUERY`, `MAP_LINK`, `MAP_EMBED` and `FORM_ENDPOINT`.

> 📌 The contact form only works on the hosted site (an `https://` address), not from a local file. On the first message, FormSubmit sends an activation email, so click it once.

### Adding a new project
Add a block to the `PROJECTS` list in `index.html`, then update the project counter in the hero.

### Deploy
Push the repository to GitHub and import it into Vercel. Every `git push` redeploys the site automatically.
